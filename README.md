# Cognitive Operator — Behavioral Science & Strategic Interaction PWA

An executive-grade, mobile-optimized Progressive Web Application designed to master human behavior, cognitive traps, and strategic interaction dynamics.

## Quick Start

### Development Server
```bash
npm run dev
```
- Local URL: `http://localhost:5174`
- Network (Phone Wi-Fi): `http://10.0.0.188:5174`

### Production Build
```bash
npm run build
```
Compiles a production-ready bundle into `/dist`.

### 1-Click Free Cloud Deployment (Vercel)
```bash
npx vercel
```
This gives you an instant public HTTPS link that you can open and install as a PWA on your phone from anywhere in the world.
